# PowerBox
Win11 UI回退及预览版功能尝鲜工具  
Windows 11 UI Rollback (To Windows 10's UI) and Insider Features Tester

## Description
After experiencing the latest Windows 11 system, I always felt that the UI loading had delays, so I developed this tool. This tool can restore the File Explorer menu bar, context menu, taskbar, Start menu, and settings of Windows 11 to the Windows 10 style, reducing loading delays. People who do not like the operating logic of Windows 11 can also use it to restore the old UI. At the same time, the tool also provides options to try out new features and hidden features of the Windows 11 Dev preview, as well as small utilities such as opening IE browser.
